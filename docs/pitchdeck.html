Why Hybrid?

If ECDSA is broken by quantum computers, ML-DSA-44 still protects funds. If ML-DSA has an undiscovered flaw, ECDSA remains secure. Both must be compromised to steal funds.

Privacy by Design

🫥

Zero Identity

No phone number, no email, no account. Ephemeral keys generated on device. Triple-tap panic wipe clears everything instantly.

📡

Minimal BLE Footprint

Announces contain only nickname + Noise pubkey. No device name, no OS info. iOS MAC randomization. Announce jitter prevents correlation.

🧅

Tor by Default

All network traffic — Nostr relays, RPC calls, Helios sync — routes through Tor. Fail-closed: no Tor = no internet. DNS over Tor (socks5h://).
